# Base task demonstrations

Eight successful, unperturbed [X-VLA](https://github.com/2toinf/X-VLA) demonstrations use the public [LeRobot checkpoint](https://huggingface.co/lerobot/xvla-libero/tree/12e8783e996944f5c97e490d37d4c145484ed70a) and official [LIBERO simulator](https://github.com/Lifelong-Robot-Learning/LIBERO/tree/8f1084e3132a39270c3a13ebe37270a43ece2a01). They illustrate tasks and do not determine leaderboard scores.

Videos use native 640 × 640 rendering, a uniform 4× speedup, a 180° display rotation and silent H.264 encoding. WebP posters share the same resolution.

Each rollout starts from an official initial state and completes its simulator success condition. Only videos and posters are published; review traces stay private.
